# Example Skill

状态：draft。复制本模板后，与 `manifest.json` 中的 id、版本和契约保持一致。

## 使用方式

在登记表中明确 standalone 或 agent_workflow。独立 Skill 由宿主当前会话直接使用，不默认需要专家 Task 或 SOP；用于专家工作流的 Skill 按对应角色、任务与授权边界执行。

## 触发条件

填写能够判断的任务条件，以及选择此技能所需的输入。

## 排除条件

填写不适用的目标、缺失前提或停止条件。有实际工作流转交需求时，单独明确接收角色与条件。

## 输入契约

列出必需和可选输入、格式、基线版本、允许的未知信息。路径输入说明相对根目录和读取范围。

## 输出契约

列出产物、证据和失败结果。有上层任务时关联其验收条件；独立 Skill 明确自身收尾与完成要求。建议方案与已执行结果分开记录。

## 专业方法

填写可复用的操作步骤、决策依据、边界检查和停止条件。工具命令说明工作目录、适用版本与实际能力需求。

## 验证与边界用例

添加至少一个正例、反例和边界用例；领域技能添加实际工程案例及结果证据。未执行、跳过和失败分别报告。

## 故障处理与恢复

区分缺少输入、环境故障、工程缺陷及未知硬件行为。记录已完成工作、可重试步骤和需要外部提供的前提。

## 参考资料与归属

维护 `manifest.json` 的 `sources`，记录真实 URL、作者、版本/提交、许可证和引用/改编/复制方式；`references/` 保存资料与说明。硬件推断标为待验证。
