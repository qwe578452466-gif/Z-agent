## 角色目标与职责

## 执行边界

确认产物类型、读写范围、工具权限、模型/宿主要求、协作与审查限制，以及 boudaries 的生成与重新核验规则。

## 专家 SOP

明确该专家总结的每次必需步骤、条件步骤、事实核验、异常停止、证据与交接。SOP(each run) 是固定版本的专家总结，不能将某次任务的目录或硬件假设固化为通用规则。

## 输入输出与协作

确认 Task 接收、Result/evidence/sop_checks 提交、依赖、分派和独立 Reviewer 接口。

## 失败、恢复与生命周期

确认启动、重试、会话恢复、检查点、未知副作用和持久化边界。权限与生命周期能力由宿主提供。

## 验收与维护

定义角色合格标准、正反例、边界用例、SOP 核对、版本变更和对应证据。

## 访谈记录与确认

访谈每轮只问一个问题；背景说明围绕实际问题，场景未明确时不预设答案、推荐或方案对照。模糊问题先解释背景、依赖与取舍，帮助用户拆解，再讨论选择，不直接列选项和推荐。当前独立访谈会话主动指出缺口、说明影响、指导和建议补齐，然后回到原问题。每次问题以 JSON 保存，每次回答记录，参考 OMC；按问题 ID 保存实际讲解、原始答案、确认来源和未决项，以及缺口与原问题的关系。访谈历史全部保留，当前需求与项目默认以最新访谈内容迭代；同一事项的新内容优先，未被修改的事项继续保留，需求汇总与原始记录分开。后续 Skill 对同一 Agent 的补充以增量记录，通用职责发生变化时重新核对受影响的已确认要求。

本角色必要需求和摘要未确认前，不推进下一项；它不参与独立 Skill 的访谈执行。
