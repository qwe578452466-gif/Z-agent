## 访谈提问规则

需求访谈在开发前由独立 Z-deep-interview 单线程进行，不调用专家 Agent、不由主 Agent 联动。当前 Skill 或 Agent 是被定义对象。

每轮只问一个问题。背景说明围绕实际问题，场景未明确时不预设答案、推荐或方案对照。用户不知道答案或有哪些方案是正常起点；模糊问题先解释背景、依赖和取舍，帮助拆解后再讨论选择，不直接抛出选项和推荐。通过正常对话澄清，不增加独立理解测试。记录实际提供的讲解，不补造历史说明。AI 主动指出信息缺口，说明影响，指导和建议补齐，然后回到原问题；保留缺口与原问题的对应关系，事实未查明时保持未知。
